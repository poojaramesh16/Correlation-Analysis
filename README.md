Correlation Analysis Using Python

📌 Project Overview

This project demonstrates correlation analysis using Python to understand the relationship between different variables. It explores the strength and direction of relationships using statistical methods and data visualization techniques.

The project uses simulated data to analyze the relationship between study hours, exam scores and sleep hours.

🎯 Objectives

- Understand the concept of correlation.
- Measure relationships between variables.
- Compare Pearson and Spearman correlation.
- Analyze the impact of outliers on correlation.
- Visualize relationships using a correlation heatmap.
- Understand the difference between correlation and causation.

🛠️ Tools and Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- SciPy
- Google Colab / Jupyter Notebook

📚 Topics Covered

1. Introduction to Correlation
2. Pearson Correlation
3. Spearman Correlation
4. Outlier Impact Analysis
5. Correlation Matrix Heatmap
6. Anscombe's Quartet
7. Correlation vs Causation
8. Applications in Machine Learning and AI

📊 Key Analysis

- Analyzed the relationship between study hours and exam scores.
- Examined the relationship between sleep hours and exam scores.
- Compared Pearson and Spearman correlation before and after adding an outlier.
- Created a correlation matrix heatmap.
- Visualized Anscombe's Quartet to understand why data visualization is important.

💻 How to Run

1. Clone or download this repository.
2. Open the notebook using Google Colab or Jupyter Notebook.
3. Install the required libraries if necessary.

pip install numpy pandas matplotlib scipy

4. Run all cells sequentially to view the results and visualizations.

📈 Outcome

The project demonstrates how correlation methods help identify relationships between variables. It also shows how outliers can influence correlation values and why visualizing data is important before making conclusions.

📝 Conclusion

This project provides practical knowledge of statistical correlation techniques using Python. It improves understanding of data analysis, statistical relationships and visualization, which are useful in Data Analytics and Machine Learning.
